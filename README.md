# Bible Reader content — TL-Tagalog

This repository contains the Bible Reader SD-card content for **TL-Tagalog**.

## Directory layout

- `text/TL-Tagalog/` — all Bible translations and their original nested folder structure.
- `audio/TL-Tagalog/` — audio Bible book folders and chapter MP3s.
- `gospel/TL-Tagalog/` — Gospel files, retaining original names such as `Gospel.txt` and `Gospel.mp3`.

Copy these folders into the root of the Bible Reader `SDCARD` staging directory.
Do not rename files or flatten directories: the firmware expects the original paths.
